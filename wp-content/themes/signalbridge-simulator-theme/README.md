
# SignalBridge Simulator (Theme-Only)

A lightweight WordPress theme that provides:
- Private site redirect (theme-only)
- Custom Post Types: News Articles, Social Posts
- Scenario taxonomy & scenario page template
- Author alias meta (no plugin)
- Pin to top, Breaking label, simple oEmbed for news
- Mixed Home Feed with filters (All, News, Tweets, Facebook, Instagram)
- Mobile-friendly cards

## Quick Install
1. Download the ZIP and upload via **Appearance → Themes → Add New → Upload**.
2. Activate the theme.
3. Create a **page** titled "Home" and assign the template **Home Feed (Mixed)**. Set it as the **Homepage** in Settings → Reading.
4. Create pages named with exercise acronyms (e.g., `APCex`, `GOA`) and assign the template **Scenario Page (by slug)**. Create a Scenario term with the same slug and assign it to posts.
5. Create sample **News Article** and **Social Post** items from the dashboard.

## Notes
- For manual user approval and advanced fields, install plugins separately as needed.
- This theme adds a footer link to SignalBridge.com per project requirements.
