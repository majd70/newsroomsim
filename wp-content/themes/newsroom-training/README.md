# Newsroom Training Platform WordPress Theme

A WordPress theme that simulates a mini newsroom environment for training exercises. Features news articles and social media content management with different user roles.

## Installation

### For WordPress Installation

1. **Download the theme files**
   - Copy the entire `newsroom-training` folder to your WordPress themes directory
   - Location: `/wp-content/themes/newsroom-training/`

2. **Activate the theme**
   - Go to WordPress Admin → Appearance → Themes
   - Find "Newsroom Training Platform" and click "Activate"

3. **Set up user roles**
   - The theme automatically creates two custom user roles:
     - **Newsroom Operator**: Can create and manage content
     - **Newsroom Trainee**: Read-only access
   - Assign these roles to users as needed

4. **Create content**
   - Go to WordPress Admin → News Articles → Add New
   - Go to WordPress Admin → Social Posts → Add New
   - Use the custom meta boxes to add additional details

## Features

- **Custom Post Types**: News Articles and Social Media Posts
- **Custom Taxonomies**: News Categories, Social Platforms, Training Scenarios
- **User Roles**: Operators (content creators) and Trainees (viewers)
- **Responsive Design**: Mobile-friendly Bootstrap-based layout
- **Content Filtering**: Filter by content type and training scenario
- **Access Control**: Private content requiring user login
- **Custom Meta Fields**: Rich metadata for articles and social posts

## Content Types

### News Articles
- Breaking news indicator
- Custom author names
- Featured images
- Video embeds
- Categories
- Training scenario assignment

### Social Media Posts
- Platform selection (Twitter, Facebook, Instagram)
- Custom display names and handles
- Avatar images
- Media attachments
- Engagement metrics (likes, comments, shares)
- Training scenario assignment

## User Management

### Newsroom Operators
- Can create, edit, and delete news articles and social posts
- Access to all admin features
- Can assign content to training scenarios

### Newsroom Trainees
- Read-only access to published content
- Cannot create or edit content
- Requires login to view any content

## Customization

### Styling
- Bootstrap 5 based responsive design
- Custom CSS variables for easy color customization
- FontAwesome icons included

### Content Organization
- Filter content by type (All, News, Twitter, Facebook, Instagram)
- Organize content by training scenarios
- Pin important posts to the top
